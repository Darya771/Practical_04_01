# Практическое занятие 4 · Вариант 1

Наземная станция и эмулятор БПЛА обмениваются четырьмя типами сообщений MAVLink 2 через UDP на одном компьютере. НСУ использует порт 14540, эмулятор — 14551. Оба приложения работают на адресе 127.0.0.1.

## Запуск в Qt Creator

1. Распакуйте архив. Откройте `Practice4.pro` в Qt Creator и выберите набор Desktop с Qt 5.15 или Qt 6 и компилятором с поддержкой C++17.
2. Соберите проект целиком (Ctrl+B). В конфигурациях запуска выберите `GroundStation`, запустите её и нажмите «Открыть канал».
3. Запустите `UavSimulator` из второй конфигурации запуска и нажмите «Запустить БПЛА». Если Qt Creator останавливает первый процесс при смене цели, запустите второй файл из каталога сборки `simulator`. Файл станции находится в `station`. На Windows исполняемые файлы могут лежать во вложенной папке `debug` или `release`.
4. В НСУ задайте 80 м, нажмите «Взлёт» и подтвердите действие. После набора высоты нажмите «Посадка». Сравните знаки вертикальной скорости на графике.

## Проверка варианта 1

| Действие в эмуляторе | Что видно в НСУ |
| --- | --- |
| Запустить БПЛА | Зелёный индикатор, координаты и две серии графика |
| Включить «Снизить телеметрию до 2 Гц» | Жёлтый индикатор |
| Пропустить два пакета | Счётчик потерь +2, запись в журнале |
| Испортить CRC или обрезать пакет | Счётчик ошибок +1, запись в журнале |
| Включить «Не отправлять COMMAND_ACK» и дать допустимую команду | Через 3 с статус «Подтверждение не получено» |
| Включить «Отказ сенсора» и дать команду | Аварийный режим и отказ по COMMAND_ACK |
| Отключить БПЛА, дождаться потери связи, запустить и снова отключить | Красный статус и блокировка команд при каждой потере. Диалог появляется только в первый раз за запуск НСУ |

Форма НСУ редактируется в `station/mainwindow.ui`. `TelemetryModel` хранит параметры, `MavlinkManager` отвечает за приём и команды, `MavlinkMessageParser` проверяет кадры, `UavSimulator` моделирует полёт и сбои.
